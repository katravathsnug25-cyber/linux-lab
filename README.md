# Linux Shell Scripting Lab (linux-lab)

Step-by-step Linux shell scripting progression built inside an Ubuntu Docker workspace.

## Scripts Roadmap

| Level | Script | Focus Area |
| :--- | :--- | :--- |
| 01 - Basic | hello_linux.sh | Shebang, echo, system kernel check (uname -a) |
| 02 - Basic | sys_info.sh | Variables, command substitution, disk & RAM diagnostics |
| 03 - Logical | 03_file_ops_logic.sh | Conditional statements (if/else), directory & file checks |
| 04 - Logical | 04_loops_audit.sh | for loops, arithmetic counters, permissions & size audit |
| 05 - CEO / Ops | 05_health_guard.sh | Resource thresholds, awk parsing, exit codes (0/1) |
| 06 - Master | 06_log_backup_engine.sh | Functions, timestamped logging (tee), tar.gz backups |

## Quick Run
chmod +x *.sh && ./06_log_backup_engine.sh
